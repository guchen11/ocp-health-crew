Warm Start vs. Clean Start - Why It Matters

Clean start: The cluster has no test VMs running, CSI caches are cold, and no prior test activity has warmed up internal caches or metadata. This is the realistic starting condition for a production 10K run.

Warm start: The cluster was already active from prior test runs (Phase 1 isolated tests). CSI plugin caches, Ceph metadata caches, and OMAP lookups are pre-loaded from recent activity. This makes early batches artificially faster, but the accumulated pressure from prior activity causes steeper degradation over time.

Why it matters: Phase 2 ran with a warm start and showed 1,525 VMs/hr early on (artificially fast) but degraded 41%. Phase 3 ran from a clean start and showed more moderate but sustainable throughput with only 5% degradation. For projecting a real 10K run, clean-start data (Phase 3) is what we trust.

Projection Methodology

Projections use a conservative degradation model: the Phase 3 degradation rate (5-9%) applied per 1,000-VM segment, compounding. We also factor in the Phase 2 observation of steeper degradation (41% over 1K VMs) as a stress-case upper bound. The 50/batch projection uses a weighted average of both observations.

Recommendation: 50 VMs per Batch

Based on all four test phases, 50 VMs/batch is the optimal batch size for the 10K VM run.

Higher throughput1,107 VMs/hr steady-state vs 1,045 VMs/hr for batch-25 (6% faster)
Lower degradation5% degradation at 1K VMs vs 9% for batch-25
Half the batches200 batches vs 400 - less YAML generation overhead, fewer API calls
Safe CSI memoryProjected 1.6Gi at 10K, well under the current 8Gi precautionary limit (20% utilization). The 8Gi limit will be right-sized after the test based on actual peak usage.
Proven at scaleConsistent results across Phase 1, 2, and 3 tests

Estimated 10K completion time: ~8 hours (conservative), with projected CSI memory peaking at ~1.6Gi.

Risk mitigation: Monitor CSI memory every 500 VMs. If growth exceeds 0.2Mi/VM (versus observed 0.095Mi/VM), pause and assess. The 8Gi limit provides 6.2Gi of headroom beyond the projected peak.
